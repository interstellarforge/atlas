# ADR-0001: License

- Status: accepted (AGPL-3.0)
- Date: 2026-10-27

## Context

Atlas is open source and self-hosted, offered possibly as a network service. The choice is legal/philosophical, not technical.

## Decision

Proposed: AGPL-3.0. Modified versions offered as a network service must remain open source. Alternative: MIT (more permissive, no such guarantee).

## Consequences

AGPL may deter some corporate adopters and constrains embedding in closed products. MIT maximizes adoption but allows closed forks. Decide before first public release (task in REL: release readiness).
